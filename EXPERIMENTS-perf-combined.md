# perf-combined: журнал экспериментов

Ветка `perf-combined` начата от `codex/publish-parquet-native-20261008` (образ `pqnative`,
`sha256:cc642cc0…`): нативный движок `perf-native` + H1-кодирование parquet + параллельное
кодирование + самостоятельный исполняемый файл `t3-native`. Цель — объединить лучшее из обеих
линий. Предыдущая история: `EXPERIMENTS.md` в ветке `perf-native`.

## Как проверяем каждый шаг
- `tools/pair_bytes.py A B units/`: побайтное сравнение parquet двух образов на всех 71 публичном
  юните. Для шагов, которые не должны менять вывод, это строгий оракул против проверенного образа.
- Официальная регрессия (65), `tools/batch_gate.py` (официальные `score_isolation` +
  `check_aggregate` на 6 batch-юнитах, флаги платформы).
- Скорость: `tools/roster71.py` — все 71 юнит (65 одиночных + 6 batch), среднее арифметическое,
  как в рейтинге; `window` = Docker StartedAt→FinishedAt, `full` = create+start+rm.
  `tools/cold_time.sh` — запуск после сброса кэша страниц.
